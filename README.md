# BIOL90042 Group Project - Group 6

## Project Overview

This repository contains the code, datasets, and Quarto reports
for our BIOL90042 group project at the University of Melbourne.

The project involves applying computational and statistical
approaches to analyse biological datasets.

## Group Information

- Course: BIOL90042
- Institution: University of Melbourne
- Group: Group 6
- Group Members: Peilin Feng, Anne-Dyanna Jayatilake, HUNG LONG NGÔ, Theoni Raptis

## Project Components

Our project includes the following analyses:

1. Population Genetics
2. RNA Sequencing
3. Drug Screening
4. Clinical Trial
5. Other analyses and collaborative tasks

## Repository Structure

- `data/` - Datasets used in the analyses
- `Group6_Population_Genetics.qmd` - Population genetics analysis
- `Group6_RNA_Seq.qmd` - RNA-seq of patient iPSC-derived neurons analysis
- `Group6_Drug_Screen.qmd` - Drug screening analysis
- `Group6_Clinical_Trial.qmd`
- `Group6_CollabQ_1 ~ Group6_Collab_Q5` - Collaboration questions
- `Group6_Population_Genetics.csv` - Population genetics CSV file
- `biol90042-project.Rproj` - RStudio project file

Additional Quarto files will be added as the project progresses.
