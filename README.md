# BIOL90042 Group Project – Group 6

## Project Overview

This repository contains the datasets, R code, Quarto reports, and supporting files for the BIOL90042 Coding and Data Analysis group project at the University of Melbourne.

The project focuses on Parkinson's disease (PD), applying computational and statistical methods to analyse biological and clinical datasets. The analyses cover population genetics, RNA sequencing, drug screening, and clinical trial data.

The project also includes collaborative questions that integrate findings across different datasets to explore the biological mechanisms underlying PD and potential directions for future research.

## Project Components

The project consists of four main analyses and five collaborative questions.

### Individual Analyses

1. **Population Genetics** (`Group6_Population_Genetics.qmd`)  
   Analysis of genetic data and polygenic risk scores (PRS) in relation to Parkinson's disease.

2. **RNA Sequencing** (`Group6_RNA_Seq.qmd`)  
   Analysis of gene expression data from patient iPSC-derived neurons, including differential gene expression.

3. **Drug Screening** (`Group6_drug_screen.qmd`)  
   Analysis of drug screening data to identify potential hit compounds and their associated gene targets.

4. **Clinical Trial** (`Group6_Clinical_trial.qmd`)  
   Statistical analysis and interpretation of clinical trial data.

### Collaborative Questions

The following Quarto files contain the group's collaborative analyses:

- `Group6_Collab_Q1.qmd`
- `Group6_Collab_Q2.qmd`
- `Group6_Collab_Q3.qmd`
- `Group6_Collab_Q4.qmd`
- `Group6_Collab_Q5.qmd`

These questions integrate findings across datasets to investigate PD-related biological mechanisms, identify potential therapeutic targets, and suggest future research directions.
