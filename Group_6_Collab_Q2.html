4. Calculate Polygenic Risk Scores (PRS)

4.1 Reshape Genotype Data

Convert the genotype data from wide to long format, with one row per donor and genetic locus.

prs_long <- ca_co_genotypes |>
  pivot_longer(
    cols = starts_with("locus_"),
    names_to = "locus",
    values_to = "dosage"
  )

4.2 Join GWAS Effect Sizes

Join the genotype data with the GWAS beta coefficients for each locus.

prs_long <- prs_long |>
  left_join(
    gwas_top_hits |>
      dplyr::select(locus, beta),
    by = "locus"
  )

Check that every locus has a matching coefficient.

sum(is.na(prs_long$beta))
[1] 0

4.3 Calculate Participant-level PRS

Calculate the weighted contribution of each locus and sum the contributions to obtain one PRS per participant.

prs_data <- prs_long |>
  mutate(weighted_score = dosage * beta) |>
  summarise(
    PRS = sum(weighted_score),
    .by = c(donorid, status)
  )

5.3 Visualise PRS by Group

Explore the relationship between polygenic risk scores and patient groups.

Using PRS to stratify participants illustrates that there tends to be higher PRS in the ‘case’ group. However, this trend emerges when we limit our sample to the participants in the rna-seq arm of the study

ggplot(
  data = b,
  aes(x = group, y = PRS, colour = PRS)
) +
    geom_jitter(width = 0.1, height = 0, size = 4) +
  labs(
    x = "Status",
    y = "Polygenic Risk Score (PRS)",
    colour = "PRS",
    title = "PRS RNA-Seq Participants Only"
  ) +
  theme_minimal()

The clustering becomes less discrete when all participants are pooled, though the ‘case’ group still appears to have a higher PRS

ggplot(
  data = prs_data,
  aes(x = status, y = PRS, colour = PRS)
) +
  geom_jitter(width = 0.1, height = 0, size = 2) +
  scale_x_discrete(limits = c("ctrl", "case")) +
  labs(
    x = "Status",
    y = "Polygenic Risk Score (PRS)",
    colour = "PRS",
    title = "PRS ALL Participants"
  ) +
  theme_minimal()
