2. Extract unique donor IDs

# Extract unique donor IDs from population genetics
prs_ids <- ca_co_genotypes |> 
  distinct(donorid)

# Extract unique donor IDS from RNAseq sample metadata
rna_ids <- dge$samples |> 
  distinct(donorid) 

# Extract unique donor IDs from clinical trial data
gait_ids <- gait_data |> 
  distinct(donorid)

3. Identify overlapping patients

# Identify donors appearing across all three datasets
# containing identifiable donor IDS

overlapping_donors <- prs_ids |> 
  # Match population genetics donors with RNAseq donors
  inner_join(rna_ids, by = "donorid") |> 
  # Keep donors also appearing in clinical trial
  inner_join(gait_ids, by = "donorid")

4. Results and Interpretation

Using the unique donor IDs, we identified 8 participants who appeared in the population genetics, RNA-seq and clinical trial datasets. However, the drug screening dataset did not provide identifiable donor IDs for matching with the other datasets. Therefore, although 8 participants were confirmed to overlap across three study arms, the number of participants appearing across all four arms could not be determined from the available donor information.
